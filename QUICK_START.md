# 🌙 NightFit Tracker - Quick Start Guide

## ⚡ First 5 Minutes

### 1. Install the App
**iPhone:**
- Open in Safari → Share → Add to Home Screen → "NightFit"

**Android:**
- Open in Chrome → Menu (⋮) → Install App → Add to Home Screen

### 2. Set Your Profile
The app auto-detects:
- Height: 5'6"
- Starting weight: 68 kg
- Daily budget: 250 SAR

Edit in the app if different.

### 3. Log Your First Meal
1. Tap "Home" tab
2. Press meal buttons (eggs, roti, dal, etc.)
3. Each press = 1 portion
4. See instant calorie count ✓

### 4. Complete a Workout
1. See "Day A" or "Day B" exercise list
2. Do the exercises
3. Tap "Mark Done" ✓

### 5. Log Expense
1. Type amount in "Add expense" box
2. Hit Enter
3. Tracks toward 250 SAR limit

## 🎯 Quick Tips

### Meal Logging
- **Quick Add**: Tap meal buttons repeatedly for multiples
- **Calories**: Auto-calculated, shown in real-time
- **Protein**: Tracked automatically
- **Cost**: Deducted from 250 SAR budget

### Workout System
- **Day A**: Push-ups, incline push-ups, plank (upper)
- **Day B**: Squats, lunges, plank (lower)
- **Auto-Rotate**: Alternates every day
- **Progress**: Reps increase if consistent

### Expense Management
- **Fast Add**: Type amount, press Enter
- **Visual Budget**: See remaining balance
- **Breakdown**: See spending by food type
- **Export**: Download CSV/PDF anytime

### Energy Warnings
- **Green**: 1800+ calories (safe)
- **Yellow**: 1500-1800 calories (eat more)
- **Red**: <1500 calories (dizziness risk - eat banana!)

## 🚨 Common Scenarios

### "I feel dizzy at work"
1. Check calories (usually <1500)
2. Eat banana (89 cal, quick energy)
3. Or 2 eggs + roti (quick 300 cal)
4. Avoid skipping meals

### "I'm over budget"
1. Check expense breakdown
2. See which food costs most
3. Buy cheaper alternative (banana → apple)
4. Or cook in bulk

### "I missed workouts"
1. Check calendar (red days)
2. 3 days/week minimum (realistic)
3. No "all or nothing"
4. Consistency > intensity

### "Not losing weight"
1. Check calories (must be 1800 max)
2. Verify meal portions logged
3. Log weight every 3 days
4. Takes 2-3 weeks to see change

## 🆘 Troubleshooting

**Q: App won't save data?**
A: Check if browser storage is enabled. Try Safari (iOS) or Chrome (Android).

**Q: Numbers not updating?**
A: Refresh page. Data auto-saves.

**Q: Offline mode not working?**
A: Install app first (not just browser tab). Check service worker status.

**Q: Can't export PDF?**
A: Need internet connection. Try CSV first, then email yourself.
